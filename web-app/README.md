# 🧺 Çamaşırhane Yönetim Sistemi / Laundry Management System

Современное веб-приложение для управления прачечной в общежитии с поддержкой турецкого и английского языков.

## ✨ Возможности

### Для пользователей:
- ✅ Резервирование стиральных машин с выбором времени
- ✅ Резервирование вешалок для сушки (1-2 шт)
- ✅ Real-time обновления через WebSocket
- ✅ Система очередей
- ✅ Автоматическое освобождение машин
- ✅ Напоминания
- ✅ Поддержка двух языков (TR/EN)
- ✅ PWA - работает как приложение
- ✅ До 50 одновременных подключений

### Для администратора:
- 👨‍💼 Просмотр всех резерваций
- 👨‍💼 Удаление пользователей
- 👨‍💼 Изменение количества вешалок
- 👨‍💼 Просмотр очередей

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск приложения
```bash
npm run dev
```

Приложение будет доступно:
- Фронтенд: http://localhost:5173
- Бэкенд API: http://localhost:3000
- WebSocket: ws://localhost:3000

Сервер принимает до 50 одновременных подключений браузеров/устройств. Каждая вкладка считается отдельным подключением. После достижения лимита новое подключение получит сообщение о необходимости попробовать позже. Лимит можно изменить переменной окружения `MAX_CONNECTED_USERS`.

### 3. Первый вход

При первом входе введите:
- **Имя**: Ваше имя

Телефон не требуется: приложение создаёт и сохраняет локальный идентификатор пользователя.

### 4. Настройка администратора

Для активации админ-панели нужно установить админа:

Сначала войдите в приложение под учётной записью, которой нужно выдать права. Затем откройте консоль браузера и выполните:
```javascript
fetch('/api/admin/set', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    userId: localStorage.getItem('userId'),
    password: 'admin123'
  })
}).then(r => r.json()).then(console.log)
```

⚠️ **Важно**: Пароль по умолчанию `admin123` - измените его в `server/index.js` перед продакшеном!

## 📱 Использование

### Резервирование стиральной машины:
1. Нажмите кнопку "Ayırt" / "Reserve" на свободной машине
2. Выберите время стирки (15-180 минут)
3. Подтвердите резервацию
4. После окончания нажмите "Bitti" / "Finish"

### Резервирование вешалок:
1. Нажмите "Askı Ayırt" / "Reserve Rack"
2. Выберите количество (1 или 2)
3. Подтвердите резервацию
4. Через 2 дня придет напоминание

### Автоматическое освобождение:
- После окончания стирки у вас есть **10 минут** забрать вещи
- Если не нажать "Bitti", машина освободится автоматически
- Следующий в очереди получит машину автоматически

## 👨‍💼 Админ-панель

После установки админа в заголовке появится кнопка "Admin Paneli".

### Возможности админа:
- **Просмотр всех резерваций** - кто что занял
- **Удаление пользователей** - если кто-то забыл освободить
- **Изменение количества вешалок** - увеличить/уменьшить

## 🔧 API Endpoints

### Публичные:
- `GET /api/status` - получить текущее состояние
- `POST /api/wash/reserve` - зарезервировать машину
- `POST /api/dry/reserve` - зарезервировать вешалки
- `POST /api/finish` - завершить использование
- `POST /api/cancel` - отменить резервацию
- `POST /api/admin/check` - проверить админа

### Админские:
- `POST /api/admin/set` - установить админа
- `POST /api/admin/remove` - удалить пользователя
- `POST /api/admin/racks/count` - изменить количество вешалок

## 🌐 Деплой

Для использования с iPhone приложение нужно разместить на публичном HTTPS-адресе. Для Android APK также потребуется указать публичный адрес сайта/API; `localhost` работает только на компьютере, где запущен сервер.

### Android APK

1. Установите Android Studio и Android SDK.
2. В PowerShell укажите публичный HTTPS-адрес backend-сервера и соберите Android-проект:
   ```powershell
   $env:VITE_API_URL = "https://ВАШ-ДОМЕН"
   npm run android:sync
   npm run android:open
   ```
3. В Android Studio выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Для установки APK на Android найдите файл в `android/app/build/outputs/apk/debug/app-debug.apk`.

Для iPhone достаточно открыть публичный HTTPS-адрес в Safari и добавить сайт на главный экран. Не используйте `localhost` в опубликованной сборке: он указывает на само устройство.

### Локальная сеть:

1. Узнайте IP адрес:
```bash
ipconfig  # Windows
ifconfig  # Linux/Mac
```

2. Измените в `src/App.jsx` строку 25:
```javascript
const websocket = new WebSocket(`ws://ВАШ_IP:3000`);
```

3. Соберите проект:
```bash
npm run build
```

4. Запустите сервер:
```bash
npm run server
```

Теперь доступно по адресу: `http://ВАШ_IP:3000`

### Интернет (Heroku, Railway, etc):

1. Создайте переменную окружения `PORT`
2. Измените WebSocket на использование `window.location.hostname`
3. Настройте переменную `NODE_ENV=production`

## 🔐 Безопасность

⚠️ **Перед продакшеном**:
1. Измените пароль админа в `server/index.js`

3. Добавьте rate limiting
