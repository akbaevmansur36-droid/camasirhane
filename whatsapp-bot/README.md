# 🧺 WhatsApp Бот для управления прачечной

Бот для управления очередью на стиральные машины и вешалки для сушки в общежитии.

## 📋 Возможности

- ✅ 2 стиральные машины
- ✅ 10 вешалок для сушки (можно бронировать 1-2)
- ✅ Автоматическая очередь
- ✅ Напоминания о завершении стирки
- ✅ Просмотр статуса в реальном времени

## 🚀 Установка

### 1. Установите Node.js

Скачайте и установите Node.js с официального сайта: https://nodejs.org/ (версия 18 или выше)

### 2. Установите зависимости

```bash
npm install
```

### 3. Запустите бота

```bash
npm start
```

### 4. Авторизация в WhatsApp

После запуска в консоли появится QR-код:
1. Откройте WhatsApp на телефоне
2. Перейдите в **Настройки** → **Связанные устройства**
3. Нажмите **Привязать устройство**
4. Отсканируйте QR-код из консоли

✅ Готово! Бот теперь работает.

## 📱 Команды бота

| Команда | Описание |
|---------|----------|
| `/start` или `/помощь` | Показать справку |
| `/стирка` | Занять стиральную машину |
| `/сушка [1-2]` | Забронировать вешалки (например: `/сушка 2`) |
| `/очередь` | Посмотреть текущий статус |
| `/готово` | Завершить использование (освободить ресурсы) |
| `/отмена` | Отменить бронь и выйти из очереди |

## 💡 Примеры использования

**Занять стиральную машину:**
```
/стирка
```
→ Бот ответит: "✅ Машина 1 занята! ⏱️ Время стирки: ~60 минут"

**Забронировать 2 вешалки:**
```
/сушка 2
```
→ Бот ответит: "✅ Вешалки 3, 4 забронированы!"

**Посмотреть очередь:**
```
/очередь
```

**Завершить использование:**
```
/готово
```

## 🔧 Настройка

### Изменить время стирки

В файле `index.js` найдите строку:
```javascript
scheduleReminder(userId, freeMachine.id, 60);
```
Измените `60` на нужное количество минут.

### Изменить количество вешалок

В файле `index.js` найдите строку:
```javascript
dryingRacks: Array.from({ length: 10 }, (_, i) => ({
```
Измените `10` на нужное количество.

## 📊 Файлы данных

Бот сохраняет данные в файл `data.json`. Этот файл создаётся автоматически при первом запуске.

**Не удаляйте этот файл** во время работы бота - в нём хранится вся информация о текущих бронированиях и очереди.

## ⚠️ Важно

- Бот должен работать постоянно (компьютер должен быть включён)
- WhatsApp должен быть привязан к боту
- Если бот перезапускается, нужно заново сканировать QR-код (или использовать сохранённую сессию)

1. Откройте Task Scheduler
2. Создайте новую задачу
3. Триггер: При запуске системы
4. Действие: Запустить программу `node` с аргументами `C:\Users\akbae\whatsapp-laundry-bot\index.js`

## 🐛 Решение проблем

**QR-код не появляется:**
- Убедитесь что Node.js установлен
- Попробуйте переустановить зависимости: `npm install`

**Бот не отвечает:**
- Проверьте что бот запущен (`npm start`)
- Убедитесь что WhatsApp привязан к боту

**Ошибка авторизации:**
- Удалите папку `.wwebjs_auth` и заново авторизуйтесь
