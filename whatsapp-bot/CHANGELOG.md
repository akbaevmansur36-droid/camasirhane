# История изменений / Changelog

## [1.1.0] - 2026-11-07

### ✅ Исправлено / Fixed
1. **Все сообщения теперь приходят только в личку**
   - Раньше команды `/sira`, `/bitti`, `/iptal` отвечали в группу
   - Теперь все ответы бота приходят только в личные сообщения
   - Команды `/help` и `/yardim` тоже в личку

2. **Автоматическое освобождение машин**
   - После окончания стирки пользователю приходит напоминание
   - Через 10 минут после окончания - предупреждение об автоосвобождении
   - Ещё через 10 минут машина автоматически освобождается
   - Следующий в очереди автоматически получает машину

3. **Добавлены имена пользователей**
   - Теперь сохраняется `userName` для всех резерваций
   - Имена отображаются в логах бота

### 📋 Логика работы / Flow

**Стирка:**
1. Пользователь: `/yikama 45` (45 минут)
2. Бот: "Машина X зарезервирована на 45 минут"
3. Через 45 минут: "Стирка завершена! Заберите вещи и отправьте /bitti"
4. Сразу же: "Машина освободится автоматически через 10 минут"
5. Через 10 минут (если не отправил /bitti): Машина освобождается
6. Следующий в очереди автоматически получает машину

**Сушка:**
- Пользователь: `/kurutma 2` (2 вешалки)
- Через 2 дня: Напоминание забрать вещи
- Пользователь отправляет `/bitti` когда готов

### 🔄 Автоматическая очередь / Auto Queue
- Когда пользователь освобождает машину через `/bitti` - следующий получает её
- Когда машина освобождается автоматически - следующий тоже получает её
- Пользователь в очереди получает личное сообщение с машиной и временем
